# 班级共修管理系统简明使用说明

访问地址：<http://jingxin.myds.me:3003/>

## 一、登录与通用操作

- 管理员使用管理员账号登录；辅导员和班长使用手机号登录。
- 手机号未写国家区号时，系统默认按中国大陆 `+86` 处理。
- 使用临时密码第一次登录时，必须先设置新密码。
- 管理多个班级的管理员或辅导员，可在页面顶部的“切换班级”中选择当前班级。
- 离开考勤页面或切换班级前，请先保存；有未保存内容时系统会提示确认。
- 系统支持电脑和手机浏览器，手机上会用学员卡片显示考勤和统计。

## 二、管理员使用说明

管理员可以查看和管理全部班级。

### 第一次使用建议顺序

1. 在“全部班级”中选择“新建辅导员”，填写姓名和手机号，并把系统生成的临时密码交给本人。
2. 选择“创建新班级”，填写班名、选择负责辅导员，并设置 1–5 个小组；默认是 3 组。
3. 进入班级后，在“学员名单”中逐个新增学员，或下载模板后使用“Excel 导入”。
4. 在“班级设置”中从在册学员里选择班长，并把临时密码交给班长。
5. 在“课表安排”中设置第一课的班修截止日并生成课表；默认一次生成 24 课。

### 日常管理

- “全部班级”：创建和切换班级，并按“全部、正常、已停用”筛选。管理员可停用、恢复班级；从未添加学员或课表的空班级可以永久删除。
- “管理辅导员”：停用或恢复辅导员账号。仍负责未归档班级时，必须先在相应班级设置中转交班级；只有从未关联任何业务数据的误建账号才能永久删除。
- “学员名单”：维护姓名、法名、手机号、小组、状态、身份和备注。状态分为正常、休学、退学，只有正常学员参与完成率统计；状态和转组从下一课起生效，不改变历史。
- “学员身份”：默认显示“学员”，还可多选组长、慈善、传灯、文宣；每组只能有一名组长。这些身份只作名册标签，不增加账号权限。班长身份与班级设置中的任命自动同步。
- “Excel 导入”：模板包含姓名、法名、电话、小组、状态、身份、备注。多个身份用顿号分隔；班长不能通过 Excel 设置。
- “小组管理”：把小组调整为 1–5 组并修改组名。减少小组前，要先把其中的学员转走。
- “课表安排”：设置普通课、复习课、同周完成或平行两周，并可插入放假/暂停周。
- “班级设置”：修改班名、更换辅导员、任命或更换班长；点击“取消班长权限”可立即撤任班长；也可停用或恢复班级。
- “考勤登记”：可补填或修改所有历史考勤。
- “完成统计”：查看班级、小组和个人数据，并导出 Excel 或 CSV。

注意：更换或停用辅导员后，原辅导员立即失去相应权限；取消班长权限后，原班长立即停止访问本班；这些操作都不会删除历史数据。

## 三、辅导员使用说明

辅导员只能查看和管理自己负责的班级，一个辅导员可以负责多个班级。

### 可以做什么

- 创建新班级；创建时自己自动成为负责辅导员。
- 在“全部班级”中按状态筛选自己负责的班级，并停用或恢复班级；辅导员不能永久删除班级。
- 修改班名、小组、学员名单和课表。
- 从本班在册学员中任命或更换班长。
- 登记和补改本班全部历史考勤。
- 查看个人、小组和全班三项完成率，并导出报表。
- 查看学员手机号和内部备注。

### 建议的日常流程

1. 先在顶部确认当前班级。
2. 在首页查看当前课次、最近完成率和需要补登记的小组。
3. 检查班长填写的考勤，必要时进入“考勤登记”补改。
4. 进入“完成统计”查看“需关注”名单和三项完成率。
5. 需要留档时，按当前时间范围导出 Excel 或 CSV。

## 四、班长使用说明

班长只负责自己所在班级的考勤和统计，不能维护班级资料。

### 可以做什么

- 查看本班首页、课表、考勤和统计。
- 按全班或某个小组批量登记，再逐人修改例外情况。
- 查看个人、小组和全班的三项完成率。

### 每课考勤登记步骤

1. 进入“考勤登记”，在顶部选择课次。
2. 选择“全班”或某个小组。
3. 先使用批量操作填写多数人的状态。
4. 再逐位调整特殊情况。
5. 检查页面底部的“待保存”人数和项目数。
6. 点击“保存本课考勤”，确认影响人数后完成保存。

班长不能查看学员手机号和备注，也不能修改名单、小组、课表或班级设置。班修截止日超过 14 天后，班长不能再修改该课，需联系辅导员补改。

## 五、三项考勤怎么填写

| 指标 | 可选状态 | 计为完成 |
| --- | --- | --- |
| 导图/提纲 | 是、否；复习课自动为“不需要” | 是 |
| 组修 | 出勤、缺勤 | 出勤 |
| 班修 | 现场、网络、补课、分享、缺勤 | 现场、网络、补课 |

- 未填写会显示为“待登记”，不进入完成率分母。
- “不需要”不进入统计。
- 三项指标分别统计，不合并成一个总分。

## 六、完成统计说明

- “最近”：当前进行中的课；没有进行中课次时，显示最近结束的一课。
- “当月”：当前自然月。
- “最近 3 个月”：从今天往前滚动三个月。
- “历史”：班级开始至今天。
- 可分别查看全班概况、小组汇总、个人统计和“需关注”名单。
- “需关注”只根据班修判断，用于提示辅导员进一步了解情况，不代表对学员作最终评价。

## 七、常见问题

**忘记密码怎么办？**

联系管理员重置密码。重置后会获得新的临时密码，登录时需要再次修改。

**为什么复习课不能填写导图/提纲？**

复习课默认不要求该项，系统会自动标记为“不需要”。

**为什么新学员或转组没有出现在已开始的课次中？**

名单变化从下一课起生效，已开始课次保留当时的名单和小组，避免历史统计被改变。

**为什么完成率显示“不适用”？**

当前范围没有适用且已到期的数据，完成率分母为零。
