# 班级共修管理系统简明使用说明

访问地址：<http://jingxin.myds.me:3003/>

## 一、登录与通用操作

- 管理员使用管理员账号登录；辅导员、班长和考勤员可使用手机号或分配的拼音账号登录。
- 手机号未写国家区号时，系统默认按中国大陆 `+86` 处理。
- 使用临时密码第一次登录时，必须先设置新密码。
- 管理多个班级的管理员或辅导员，可在页面顶部的“切换班级”中选择当前班级。
- 所有登录账号都可以进入“我的资料”修改个人信息。手机号可以留空，登录账号独立保存；修改手机号或登录账号时必须输入当前密码。法名之后发生变化，不会自动改变登录账号。
- 离开考勤页面或切换班级前，请先保存；有未保存内容时系统会提示确认。
- 系统支持电脑和手机浏览器，手机上会用学员卡片显示考勤和统计。

## 二、管理员使用说明

管理员可以查看和管理全部班级。

### 第一次使用建议顺序

1. 在“全部班级”中选择“添加辅导员”。已有学员可直接搜索并选择，系统会复用其人员资料和原账号；没有账号时才生成账号和临时密码。也可以切换到“新建人员”，姓名和法名至少填写一项，手机号可以留空；无手机号时按姓名或法名生成可修改的拼音账号。
2. 选择“创建新班级”，填写班名、选择负责辅导员，并设置 1–5 个小组；默认是 3 组。
3. 进入班级后，在“学员名单”中逐个新增学员，或下载模板后使用“Excel 导入”。
4. 在“班级设置”中从正常在册学员里选择班长；需要协助登记时，也可设置一名或多名考勤员。没有手机号时可填写希望使用的拼音账号，也可让系统自动生成；把登录账号和临时密码交给本人。
5. 在“课表安排”中选择课程体系、学习遍数、起始课和第一课班修截止日，再生成课表。起点之前的课不会生成或统计；复习课会自动识别。管理员可手工刷新官网课程目录快照，日常排课不依赖官网实时可用。

### 日常管理

- “全部班级”：创建和切换班级，并按“全部、正常、已停用”筛选。管理员可停用、恢复班级；从未添加学员或课表的空班级可以永久删除。
- “管理辅导员”：可查看辅导员兼任学员、班长或考勤员的情况，编辑姓名、法名、手机号和登录账号，也可停用或恢复账号。修改手机号或登录账号时必须输入管理员当前密码。仍负责未归档班级时，必须先在相应班级设置中转交班级；只有从未关联任何业务数据的误建账号才能永久删除。
- “学员名单”：维护姓名、法名、手机号、小组、状态、身份和备注；姓名和法名至少填写一项。普通学员的手机号可以留空。管理员修改已绑定班长或辅导员账号的手机号时，需要输入管理员当前密码；已有拼音账号会继续保留。状态分为正常、休学、退学，只有正常学员参与完成率统计；状态和转组从下一课起生效，不改变历史。
- “学员身份”：默认显示“学员”，还可多选组长、慈善、传灯、文宣；每组只能有一名组长。这些身份只作名册标签，不增加账号权限。班长和考勤员身份与班级设置中的任命自动同步。
- “Excel 导入”：模板包含姓名、法名、电话、小组、状态、身份、备注，普通学员的电话内容可以留空。无电话学员再次导入时按“姓名＋法名”匹配；本班有多名同名同法名学员时会提示冲突。多个身份用顿号分隔；班长不能通过 Excel 设置。
- “小组管理”：把小组调整为 1–5 组并修改组名。减少小组前，要先把其中的学员转走。
- “课表安排”：从本地课程快照选择课程体系、遍数和准确起点，设置普通课、复习课、同周完成或平行两周，并可插入放假/暂停周。界面统一使用“佛法要领”名称。
- “班级设置”：修改班名、更换辅导员、任命或更换班长，并可新增多位考勤员；可分别重置临时密码或立即取消权限；也可停用或恢复班级。
- “考勤登记”：可补填或修改所有历史考勤。
- “完成统计”：查看班级、小组和个人数据，并导出 Excel 或 CSV。

注意：更换或停用辅导员后，原辅导员立即失去相应权限；取消班长或考勤员权限后，原账号立即停止以该身份访问本班；这些操作都不会删除历史数据。

同一人可以在一个班作为学员、班长或考勤员，同时在其他班担任辅导员，所有身份共用一套人员资料和登录账号。如果把某人指定为其本人所在班级的辅导员，系统会保留其学籍，并自动取消其在该班重复的班长或考勤员权限。

## 三、辅导员使用说明

辅导员只能查看和管理自己负责的班级，一个辅导员可以负责多个班级。

### 可以做什么

- 创建新班级；创建时自己自动成为负责辅导员。
- 在“全部班级”中按状态筛选自己负责的班级，并停用或恢复班级；辅导员不能永久删除班级。
- 修改班名、小组、学员名单和课表。
- 从本班正常在册学员中任命或更换班长，并可设置多名考勤员；没有手机号时使用拼音账号。
- 登记和补改本班全部历史考勤。
- 查看个人、小组和全班三项完成率，并导出报表。
- 查看学员手机号和内部备注。
- 在“我的资料”中修改自己的姓名、法名、手机号和登录账号；手机号可以留空，法名变化不会自动改变登录账号。

### 建议的日常流程

1. 先在顶部确认当前班级。
2. 在首页查看当前课次、最近完成率和需要补登记的小组。
3. 检查班长填写的考勤，必要时进入“考勤登记”补改。
4. 进入“完成统计”查看“需关注”名单和三项完成率。
5. 需要留档时，按当前时间范围导出 Excel 或 CSV。

## 四、班长使用说明

班长负责自己所在班级的考勤、统计和未来课表，不能维护班级资料。

### 可以做什么

- 查看本班首页、课表、考勤和统计。
- 生成、追加、插入、暂停、编辑或重新生成尚未开始的未来课表；已经开始的课次和历史考勤不能改变。
- 按全班或某个小组批量登记，再逐人修改例外情况。
- 查看个人、小组和全班的三项完成率。
- 在“我的资料”中修改自己的姓名、法名、手机号和登录账号；手机号可以留空。

### 每课考勤登记步骤

1. 进入“考勤登记”，在顶部选择课次。
2. 选择“全班”或某个小组。
3. 先使用批量操作填写多数人的状态。
4. 再逐位调整特殊情况。
5. 检查页面底部的“待保存”人数和项目数。
6. 点击“保存本课考勤”，确认影响人数后完成保存。

班长不能查看学员手机号和备注，也不能修改名单、小组或班级设置。班修截止日超过 14 天后，班长不能再修改该课考勤，需联系辅导员补改。

## 五、考勤员使用说明

考勤员是本班的考勤协助账号，可由管理员或辅导员从正常在册学员中指定；同一班可以有多位考勤员。

- 可以查看本班首页、考勤页面和完成统计。
- 可以按全班或小组批量登记三项考勤，并修改例外学员。
- 可以在“我的资料”中维护自己的姓名、法名、手机号和登录账号。
- 不能查看学员电话、备注或完整名册，也不能管理课表、小组、班级设置或导出数据。
- 与班长相同，班修截止日超过 14 天后不能再修改该课，需联系辅导员补改。

## 六、三项考勤怎么填写

| 指标 | 可选状态 | 计为完成 |
| --- | --- | --- |
| 导图/提纲 | 是、否；复习课自动为“不需要” | 是 |
| 组修 | 出勤、缺勤 | 出勤 |
| 班修 | 现场、网络、补课、分享、缺勤 | 现场、网络、补课 |

- 未填写会显示为“待登记”，不进入完成率分母。
- “不需要”不进入统计。
- 三项指标分别统计，不合并成一个总分。

## 七、完成统计说明

- “最近”：当前进行中的课；没有进行中课次时，显示最近结束的一课。
- “当月”：当前自然月。
- “最近 3 个月”：从今天往前滚动三个月。
- “历史”：默认显示班级开始至今天；也可以切换为“自定义时间段”，选择开始和结束日期后查询。开始和结束当天都会计入，各指标按自己的应完成日期分别统计。
- 可分别查看全班概况、小组汇总、个人统计和“需关注”名单。
- Excel、CSV 始终按照网页当前已经查询并显示的时间范围导出。修改自定义日期后，需要先点击“查询”才会改变网页和导出范围。
- “当前需关注”只根据截至今天的班修情况判断，不随所选历史时间段改变，用于提示辅导员进一步了解情况，不代表对学员作最终评价。

## 八、常见问题

**忘记密码怎么办？**

联系管理员重置密码。重置后会获得新的临时密码，登录时需要再次修改。

**为什么复习课不能填写导图/提纲？**

复习课默认不要求该项，系统会自动标记为“不需要”。

**为什么新学员或转组没有出现在已开始的课次中？**

名单变化从下一课起生效，已开始课次保留当时的名单和小组，避免历史统计被改变。

**为什么完成率显示“不适用”？**

当前范围没有适用且已到期的数据，完成率分母为零。
